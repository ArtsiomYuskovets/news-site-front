# Быстрый старт - Проверка Frontend

## Шаг 1: Установка зависимостей

```bash
cd site-strapi-front
npm install
```

## Шаг 2: Запуск проекта

```bash
npm run dev
```

Приложение откроется на **http://localhost:3000**

## Шаг 3: Что проверить

### ✅ Без Backend (сейчас)

1. **Приложение запускается** - нет ошибок в консоли браузера
2. **Навигация работает:**
   - Главная страница (`/`) - отображается, но без данных (это нормально)
   - Страница входа (`/login`) - форма отображается
   - Страница регистрации (`/register`) - форма отображается
3. **Компоненты рендерятся:**
   - Хедер с навигацией
   - Футер
   - Формы входа/регистрации

### ⚠️ Ожидаемые ошибки (нормально без backend):

- В консоли браузера будут ошибки 404 при попытке загрузить данные
- На главной странице будет "Статей не найдено" или спиннер
- Это нормально, так как backend еще не запущен

## Проблемы?

### Ошибка: "Cannot find module"
**Решение:** Выполните `npm install`

### Ошибка: Порт 3000 занят
**Решение:** Измените порт в `vite.config.ts` или остановите процесс на порту 3000

### Ошибка: TypeScript ошибки
**Решение:** Проверьте, что `src/env.d.ts` существует и содержит декларации для .vue файлов
